# Studio v9.2 deployment
Source: owner-provided Assembl-Studio-v9.2-Cloudflare-Ready export dated 26 Nov 2026.
Compiled single-file Studio uses the export’s WebGPU / WebGL 2 scene, photo match,
Model and planting settings. Release adapter uses the Lab’s existing
`/api/garden-site` and LINZ elevation library. No proxy, provider credential,
or shared function is added or replaced. Site levels and roof forms are
indicative; pool tools and prices are concept checks and estimates.
The normal Garden Studio URL opens v9.2. The homepage embed (`?view=bed`)
and `?view=classic` retain the previous renderer and the existing photo sketch.
