What’s the science?

Wave speed = frequency × wavelength. Beat is frequency: how many waves pass each second. Wave length is the distance between crests. Try doubling one while halving the other.

The joints move up and down; the wave pattern travels along the arm. The robot does not swim faster when you turn up the beat. This is an illustrative wave model, not a real octopus or a fluid simulation.

“Take apart” separates the shell, control core and eight articulated arms. A real robot needs actuators and control signals; the phase offset makes these arms ripple in sequence.
