Sources and limits

Where the pieces come from

This page reads catalogue.json (schema), a static snapshot built on 17 November 2026. It is not a live database: pieces change when the catalogue is rebuilt. An item found in two sources is one entry listing both.

    Limits

    • Every piece is a preview asset. None is verified as production-ready, photorealistic or dimensionally accurate.
    • Rights: cleared for use by Kate Hudson (owner); not independently verified. Commercial use is not claimed for any piece.
    • Model bounds are measured from each file. Stated sizes are copied from the source and can differ from the bounds.
    • The birds and sprigs are drawn at a common field-guide size, not life size.
    • Previews are this build’s own renders (three.js, studio light, ivory ground). Nine pieces also show the Blender render from Kate’s curated site.
    • Only compressed GLBs are served (28 MB in all). Blender masters and uncompressed GLBs exist for some pieces and are listed in each piece’s detail, but are not deployed here.
