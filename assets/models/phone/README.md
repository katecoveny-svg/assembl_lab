# Phone apparatus · Blender asset v1

Original generic educational construction authored in Blender 5.1.1. Approved softer pastel palette: cream, powder blue, lilac, mint and blush. The five apparatuses support the existing phone lesson; they contain no scientific solver.

`assembl-phone-atelier-web.glb` is the unchanged export: 1,404,456 bytes, SHA-256 `b4b19f635903b8070218b447e99cb45d0df12a03ca86b8a9c5f913c226746a42`, 42,816 triangles, 95 stable rig nodes. Contract source paths alone were normalized to repository-relative paths. The supplied rig controller is unchanged.

The canonical Blender source and reproduction scripts are in Library source ZIP `libfile_782e6fa3f22081918d2607a5e2c4b273`; the editable scene is `libfile_181ffd8d2d5c8191ad6a3266ceabfe7d`. Hero `libfile_b0ef7e855420819186dd9f2e3ef87cad`; dedicated 1600×1000 card `libfile_83a75d51b9808191ad237633dd6a9ffe`. JPEGs in this repository are compressed derivatives, with the complete object framing preserved.

Apply 30 scene units/metre once. The rig controller uses true metre gaps; `phone-asset.js` separately magnifies the wireless gap 5× and labels it. Each topic activates one apparatus only (13–37 asset mesh batches; the 113-batch all-station view is never selected). Test-yourself provides an apparatus selector without altering the experiment.

The adapter reads all values from `phone.js`. Charge/field markers are illustrations; circuit boards and exploded spacing are teaching enlargements. Battery casing and capacitor plates never change scale. The lower charts retain their original functions. Browser glass uses alpha blending and differs from offline Cycles refraction. Physical-device and AR validation are not claimed; the generic AR export button is disabled on this route to avoid exporting hidden stations and exaggerated spacing as a real-scale object.

Verification and known limits: [local integration review](../../../study/review/phone/README.md). Run `node --test study/tests/phone*.test.mjs` from the repository root.
