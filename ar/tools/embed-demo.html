assembl arembed.js · demo and test harness

A “View in your space” button for any page

Three ways in: a library id (shareable), a parametric library model, and your own three.js object exported on the fly. See the comment at the top of /ar/embed.js.

Library car

assemblAR.button(el, { model: 'lib:ute',
  params: { paint: 'rose' }, scale: 'table' })

Print Lab bike, real size

assemblAR.button(el, { model: 'lib:bike',
  params: { wheelbase: 140, frame: '#492B3E' },
  scale: 'real', label: 'Put it in the garage' })

Your own three.js object

assemblAR.button(el, { object: () => group,
  unitsPerMetre: 10, scale: 'table',
  title: 'Instanced test object', note: true })
