# Two-minute phone check

For Kate, on her own phone. Five steps. Each says what to tap and what you should see.

Why this exists: the page was checked on a computer, in Chrome and in Safari's engine, at phone size. It has not been
checked on a real phone or a real printer. Those cannot be tested from the build machine. This check covers that gap.

Do it once this version is live. Use the browser you normally use on the phone.

## Before you start

Open **lab.assembl.co.nz/architecture/**

You should see the word **assembl.** at the top left, a rose band that begins "Saved in this browser only", and the
sample project "A house on Waiheke Island" with its picture.

Nothing should run off the right-hand side. If you can drag the page sideways, note which screen.

## 1. The lists show their sources

1. Tap **Open** on the sample project.
2. Tap **04** in the row of seven boxes. The heading changes to "Detailed design".
3. Scroll to **Consent bundle**.
4. If you see a button "Add the 35 sourced items", tap it. (You will see it if the sample was already in this browser.)

You should see: each item has a small line under it such as "From Building Act 2004, section 45(1)(a), read
22 Nov 2026". Lower down, items carry an **Auckland Council** tag.

5. Tap one underlined source. The official page opens in a new tab. Close that tab.

## 2. A file is kept

1. Tap **01** in the row of seven boxes ("Predesign").
2. Scroll to **Documents**. Tap **+ Add a file**. Choose any photo.

You should see: a new document with "■ File kept in this browser", the photo's name and its size.

3. Tap **Download**. The photo opens or saves.

If instead you see a message that the browser would not keep the file, note the message. Private browsing does this.

## 3. The model opens in 3D

1. Tap **02** in the row of seven boxes ("Concept design").
2. Scroll to **The model**. Tap **Open in 3D ↗**.

You should see: a new tab with the house. After a short wait you can turn it with one finger.

The sample opens by a direct link. To check a practice's own model, attach a plan model file (.json) saved on the
phone, then tap **Open in 3D ↗**. The house should open with no second choosing. If the 3D page asks you to choose a
file, note that: it means this phone did not pass the model across.

## 4. Export says what is in it

1. Go back to the first tab. Tap **Export** near the top.

You should see: a box that says how many files are kept, with two buttons.

2. Tap **Export with the files**.

You should see: a message that ends "Files are included: 1 file" and a size. The phone saves one file.

## 5. The client pack prints clean

1. Tap **Client pack**, then **Print or save as PDF**.

You should see: the phone's print preview. White pages, no buttons, no rose band, nothing cut off at the right edge.
You do not need to print it. Close the preview.

## If something is off

Send a screenshot and the step number. Say which phone and which browser. That is enough to fix it.

## What this check does not prove

- It does not prove the page works on every phone. It proves it on yours.
- It does not prove a paper print. The preview is close, but a printer can still differ.
- It does not prove anything about a design. The page records what people did and said. It does not check a design
  against any rule.
